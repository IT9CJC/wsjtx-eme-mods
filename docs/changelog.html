v3.1.2-devel Latest

2026-11-02

Adds a Keep CQ watchdog for digital modes: after an auto-sequenced QSO completes, instead of stopping on the final 73, WSJT re-engages Auto and transmits a fresh CQ. A user-adjustable timeout (1–60 min, default 10) caps how long the loop runs without a reply. Timer resets each time a new QSO starts.

Changes

  • Keep CQ checkbox + timeout spinbox — new row below the Sh/Fast/Auto Seq row. Digital modes only (FT8/FT4/Q65/JT65/JT9); hidden in CW. Settings persisted as KeepCQEnabled and KeepCQTimeoutMin.
  • Watchdog behavior — timer arms on each post-73 CQ restart; resets on auto-sequence reply detection (REPLYING transition); cancels on any auto_tx_mode(false) (user halt, 73 complete, timeout). On timeout: calls auto_tx_mode(false), shows a brief status-bar message; checkbox stays checked for next time.
  • User manual updated — new sections 5j (dual RX/TX dial), 5k (rig-master VFO in None/Call DX), 5l (Keep CQ).

v3.1.1-devel

2026-11-02

CW panel simplification + dual RX/TX frequency dial. Main-window shows two side-by-side yellow-on-black dials with small "RX" / "TX" corner tags; TX dial is derived (nominal + TX Doppler correction, or tx_frequency() during split keyed TX) and mirrors RX when Doppler is off. The CW panel loses its sked frequency field, Lock Sked / Doppler Tracking checkboxes, and the 6 Doppler-mode radios — all of that now lives exclusively in the Astro dialog. Per-band preferred CW RX replaces the "sked preset" concept. New rig-master behavior for the None and Call DX Doppler methods: the operator's VFO is final, WSJT doesn't force the rig, and VFO moves adopt as the new sked (unless Ctl-Lock Sked Freq is checked). The Tune button is removed (Echo mode covers that use case), and Stop now aborts transmission immediately rather than waiting out TX Hold ms.

Changes

  • Dual RX + TX dial display — two side-by-side yellow-on-black dials replace the single main dial. RX is editable (wheel / click + arrow keys / kHz +-). TX is read-only; adjust via the Astro sked field. Small grey corner tags identify each dial.
  • Sked frequency moved to Astro only — removed sb_cw_sked_mhz, cb_cw_lock_sked, cb_cw_doppler, their handlers, and the per-band sked QSettings persistence (CW/SkedFreq_<band>).
  • Doppler mode radios removed from CW panel — the 6-radio grid is gone. Use the Astro dialog to select Doppler method.
  • Per-band preferred CW RX — renamed defaultSkedForBand to defaultCwRxForBand. Same values (3cm = 10368.100, 23cm = 1296.100, etc.) but now applied as the RX default on entering a CW band, not as a sked preset.
  • Rig-master Doppler for None + Call DX — in Doppler methods 0 and 5, WSJT no longer forces the rig frequency. The operator moves the VFO; the new frequency becomes the sked. Honors Ctl-Lock Sked Freq — when checked, the sked is frozen and the VFO can wander without rewriting it.
  • Tune button removed — Echo mode (and manual TX/RX) covers the antenna-tuning use case; keeps the CW panel cleaner. The dead generateContinuousTone method in CwToneGenerator is also gone.
  • Immediate Stop — the Stop button in the CW panel now aborts transmission on the spot: cancels pending TX-Hold / debounce / Doppler timers, clears live-keyer state, drops PTT, aborts CAT morse, restores CW mode. No more waiting out TX Hold ms.
  • Dial widening — each dial has minimumWidth=260 and MinimumExpanding horizontal size policy so centered 16pt digits always have clearance from the corner RX/TX tag.

v3.1.0-devel

2026-11-02

Major CW mode overhaul: a dedicated CW panel in the main window with keyer, sked frequency, Doppler mode selection, 6 editable Tx1-Tx6 macros, Tune, and a live keyer (type → immediate CW transmission). A new soundcard CW tone generator makes WSJT work with rigs that lack a CAT keyer (QRP Labs QMX in particular). Rig PTT edges are polled at 100 ms and trigger immediate Doppler correction. Transverter is now band-aware: enabling it for one band no longer disturbs any other band. Many persistence and quality-of-life improvements.

New Features

  • CW mode panel — Dedicated panel visible only in CW mode, replacing the hidden digital message/decode controls. Contains CW Keyer group (WPM, TX Offset, TX Hold, TX/RX toggle, Free-text live keyer, Send/Stop/Tune/Edit Macros, 6 editable Tx1-Tx6 macros, color-coded status label) and Sked & Doppler group (sked spinbox styled like main dial, Lock Sked, Doppler Tracking, 6 Doppler mode radios in 3x2 grid). NEW
  • Soundcard CW tone generator — New class Audio/CwToneGenerator that generates PCM audio with PARIS timing, 5 ms raised-cosine ramps, full A-Z/0-9/basic-punct Morse table. Used automatically when the rig’s Hamlib backend lacks rig_send_morse (reported at startup via a new cw_keyer_available(bool) signal). Rig is temporarily switched to Data/PktUSB so audio routes to the transmitter without mic processing. NEW
  • Live keyer — Typing in the Free-text field starts a streaming audio keyer (QMutex-protected ring buffer); each character is appended to the running stream. After TX Hold ms of no typing, the stream ends. NEW
  • Tune button — Continuous 700 Hz tone for antenna matching. Toggle; red when active. Snaps rig to sked first if a sked freq is set. NEW
  • 6 editable Tx1-Tx6 macros — Inline editable layout mirroring the digital message panel. Default Tx1 is CQ CQ CQ DE <MYCALL> ... K using the Settings callsign. Edits persist immediately. Bulk editor dialog via “Edit Macros…”. NEW
  • Rig-driven CW with fast polling — PollingTransceiver::set_poll_interval(ms) exposes dynamic polling. In CW mode, polling drops to 100 ms so external paddle PTT edges are detected quickly. On PTT edge, cwDopplerUpdate() is invoked with the right direction and the rig is re-tuned to sked + correction. NEW
  • Transverter band-aware — transverter_rx_offset(f_sky) now takes the frequency as parameter and returns 0 unless f_sky falls inside the enabled band’s range. Band edges are hard-coded per band (e.g. 3cm: 10000-10500 MHz). Fixes the bug where enabling 3cm broke 20m and 2m operation. Status bar label distinguishes IF=28.000 MHz (purple, active) from IF=28.000 (idle) (grey, configured but out-of-band). FIX
  • Per-band sked persistence — Sked saved per band in CW/SkedFreq_<band>. Band-specific defaults when no saved value exists: 3cm = 10368.100 MHz, 23cm = 1296.100 MHz, etc. On band change in CW mode, the sked for the new band is auto-loaded. NEW
  • Dial-freeze during CW TX — Main window dial display stops reading from m_rigState.frequency() while any CW TX is in progress (m_cwAudioActive or m_cwLastRigPTT). Prevents flickering between RX and TX values. NEW
  • Mode-selection safety net — Startup race could leave the Mode menu with no action checked. One-shot timer at end of constructor checks all 13 mode actions; defaults to FT8 if none is checked. FIX
  • Slim-build CMake options — New WSJT_SKIP_QMAP, WSJT_SKIP_RIGCTL, WSJT_SKIP_UDP_TOOLS, WSJT_SKIP_WSPRD. Combined with existing options, trims the install from 489 MB to 140 MB (ZIP 33 MB). NEW
  • Rig master vs. Sked master semantics — Clean rule: in No Doppler the rig has control of the frequency; in any Doppler mode active, the sked becomes master and m_freqNominal is locked to the sked value against rig-polling drift. NEW
  • CW status label with capability detection — Shows “Ready” / “Sending…” / “TX: <msg>” / “Keyer not supported by this rig” / errors with color coding (green / yellow / red). NEW

UI Simplifications in CW mode

  • Hidden: all digital-mode buttons (ft8/ft4/msk144/q65/jt65/echo/ hound), Decode/Auto/Monitor/Tune (digital), Stop, Halt Tx, Erase, Clear Avg, PWR slider, digital Tx1-Tx6 panel, decode windows, status-bar mode label, CQ only checkbox, BP (bypass) checkbox.
  • Kept: band buttons, DX Call/Grid, Log QSO, main dial display, Pwr label (shows watts during TX).
  • displayWidgets() re-invokes updateCWModeUI(true) at its end so digital-mode visibility logic does not override CW hiding.

v3.0.9-devel

2026-11-01

Microwave transverter band profiles with automatic offset computation and a persistent IF indicator in the main window status bar. The previous “Fixed Frequency Offset” settings are retired in favour of this per-band mechanism.

New Features

  • Transverter tab — Settings now has a Transverter tab (replaces the old Offset tab) with a 9-row table covering 6m, 2m, 70cm, 23cm, 13cm, 9cm, 6cm, 3cm, 1.25cm. Each row has the band's center frequency as metadata (50/144/432/1296/ 2320/3400/5760/10368/24048 MHz), a user-entered IF spinbox (MHz, 3 decimals), a read-only auto-computed Offset (band_center - IF) that updates live, and an Enabled checkbox. NEW
  • Mutually exclusive band selection — At most one band's Enabled checkbox can be ticked at a time. Ticking a different band automatically unticks the previous one. The user does not pick a band from a separate menu — the ticked Enabled row is the active transverter. NEW
  • CAT frequency translation — When a band is active, the CAT frequency sent to the rig is main_frequency - offset. Example: 3cm with IF = 432 MHz → offset = 9936 MHz; WSJT-X on 10368.100 MHz → rig dial 432.100 MHz. Rig feedback is translated back the same way so WSJT-X always displays the operating (sky) frequency. NEW
  • IF status indicator — A new label in the main window status bar shows IF=NONE (grey) when no transverter is active, or IF=432.000 MHz (purple) when a band is selected. Updates on Settings close. NEW
  • Fixed RX/TX offsets removed — The v3.0.6 Offset tab with its separate RX / TX spinboxes is gone. All transverter offsetting now goes through the per-band table. Old FixedRxOffset / FixedTxOffset QSettings keys are silently ignored.

v3.0.8-devel

2026-11-01

User-configurable rig mode for Q65 and Echo (default Data/PktUSB) with silent fallback to USB on unsupported rigs, and a persistent rig-mode indicator in the main window status bar.

New Features

  • Q65 / Echo rig mode selector — Settings > Radio has a new Q65 / Echo Rig Mode group box with a dropdown. When Q65 or Echo is selected from the Mode menu, this rig mode is sent via CAT (default Data/PktUSB). Options: Data/PktUSB, Data/PktLSB, USB, LSB, RTTY, FM. Other digital modes still use USB; CW still uses CW. NEW
  • Silent fallback to USB — If the connected rig does not advertise the selected mode in its Hamlib capability bitmask (rig->state.mode_list), USB is substituted transparently. The user’s configured choice is preserved so that reconnecting a capable rig restores the preferred mode. NEW
  • Rig-mode indicator in status bar — Replaces the previous CW-only blue label with a persistent color-coded label showing the resolved rig mode: blue CW, dark green Data/PktUSB — FM, grey USB/None. Updates on Mode menu changes and when the Settings dialog is closed. NEW

v3.0.7-devel

2026-10-17

CW added as a top-level mode in the main window Mode menu, with automatic radio mode switching between CW and USB via CAT.

New Features

  • CW in the Mode menu — CW is now an exclusive option alongside the digital modes (FT4, FT8, JT65, Q65, etc.) in the main window Mode menu. Implemented via QActionGroup. Selecting CW hides all digital-mode controls (decode, TX, mode buttons, waterfall splitter) and shows the blue CW label in the status bar. Selecting any digital mode exits CW and restores the digital-mode UI. NEW
  • Automatic radio mode switching — The Mode menu drives the radio directly: picking CW sends Transceiver::CW via Hamlib; picking any digital mode sends Transceiver::USB. No manual rig-mode change required when switching between CW and digital sessions. Uses QActionGroup::triggered so rig commands fire only on user clicks, not on internal mode handler calls. NEW
  • About dialog credit — Added “Revised and modified by IT9CJC Marcello Criscione for EME and CW Microwaves use.” Removed git hash / dirty-tree suffix from the version string.

v3.0.6-devel

2026-09-14

Language selector, fixed frequency offset, rig failure handling, and offline operation improvements.

New Features

  • Language selector — Choose between “System default” and “English” in Settings > General. Forces the UI language regardless of OS locale. Requires a restart to take effect. NEW
  • Fixed frequency offset — Separate RX and TX frequency offsets (±100 MHz) on the new Settings > Offset tab. Applied alongside station offsets before calibration. Useful for transverter IF corrections and EME microwave setups. NEW
  • Split with “None” rig — Split operation is now available when rig is set to “None”, enabling Doppler tracking calculations without a physical radio. NEW

Bug Fixes

  • Fixed frequency offset accumulation — Fixed offsets were being re-applied on every rig polling cycle because the feedback path did not subtract them back. Now correctly removed in the rig state feedback handler.
  • Rig failure dialog loop — When a rig was unavailable, the error dialog would pop up repeatedly in an infinite loop. Now shows the error once and lets the program continue without a rig. Counter resets on successful connection or explicit Retry.
  • Band frequency display without rig — When no rig is connected, switching bands now shows the correct default frequency for the selected band instead of a stale/meaningless value.
  • Doppler tracking without rig — Doppler corrections are now computed even when rig is set to “None”, regardless of monitoring state.
