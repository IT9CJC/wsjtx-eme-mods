1. Introduction

WSJT-X is an open-source program designed for amateur radio communication using very weak signals. It was started by Joe Taylor (K1JT) in 2001; Bill Somerville (G4WJS), Steve Franke (K9AN), Nico Palermo (IV3NWV), Uwe Risse (DG2YCB), Brian Moran (N9ADG), John Nelson (G4KLA), Charlie Suckling (DL3WDG), Roger Rehr (W3SZ), and Terrell Deppe (KJ5HST) are the other principal contributors.

WSJT-X provides flexible rig control for most modern amateur transceivers and special aids such as automatic Doppler tracking for EME (Earth-Moon-Earth) QSOs and lunar-echo testing. The program analyzes received passbands up to 5 kHz wide and runs on Windows, macOS, and Linux.

This fork (the EME CW Mod) extends WSJT-X with features needed for EME CW on microwave bands — CAT-driven CW mode, dual RX/TX dial, independent sked frequency with six Doppler modes, soundcard-generated CW for rigs without reliable SEND_MORSE, band-aware transverter profiles, extended TX Shift to ±200 MHz, per-callsign logbook, and more. Features added by the mod are tagged MOD throughout this guide.

1.1 New in the EME CW Mod (summary)

Headline additions versus stock WSJT-X 3.0.x:

  • CW mode as a first-class mode. A CW entry in the Mode menu hides the digital-mode UI, shows a dedicated CW panel, keys the rig via CAT SEND_MORSE or soundcard tone, and tracks Doppler continuously.
  • Six Doppler modes: Full, Constant frequency on Moon (CFOM), Call DX, Own Echoes, On DX Echoes, and None. Together with an independent Sked frequency and a Lock-Sked option.
  • Dual RX / TX dial at the top of the main window.
  • Transverter band profiles for 9 fixed microwave bands with a single "Enabled" row driving the CAT offset.
  • CAT keyer / soundcard CW toggle — essential for rigs (e.g. Icom IC-905) with unreliable Hamlib SEND_MORSE.
  • Q65 / Echo rig-mode selector (Data/PktUSB default, 6 options) with silent Hamlib fallback to USB on rigs that do not advertise the chosen mode.
  • Keep CQ for digital modes — auto-rearms CQ after each QSO's final 73, capped by a 1–60 minute watchdog.
  • Extended TX Shift to ±200 MHz (stock limit ±30 MHz).
  • Per-callsign ADIF logbook (wsjtx_log_<call>.adi) with log-source selector on Cabrillo export.
  • Mouse-wheel fine tuning: Shift = 100 Hz, Ctrl = 10 Hz, Ctrl+Shift = 1 Hz.
  • Band dropdown filter driven solely by Enable VHF features, not by decoder mode.
  • Band dropdown pick always sets the sked in every Doppler method.
  • UI language selector (System default / English).
  • Offline operation (Doppler tracking with "None" rig; Split with "None" rig via WSJT_RIG_NONE_CAN_SPLIT).

Full release-by-release details are in the release history appendix.

3. System requirements

  • SSB transceiver and antenna.
  • Computer running Windows 7 or later, macOS 10.15 or later, or Linux.
  • 1.5 GHz or faster CPU; 200 MB RAM minimum. Faster is better, especially for the FT8 multithreaded decoder.
  • Monitor with at least 1024×780 resolution.
  • Computer-to-radio interface: serial / USB CAT, or VOX for T/R switching.
  • Audio devices sampling at 48000 Hz, 16-bit.
  • Computer clock synchronized to UTC within ±1 second (and monotonically increasing, no backward steps).
Clock discipline WSJT-X requires the PC clock to tick smoothly forward — no SNTP step corrections. On Windows, Meinberg NTP Client or a properly configured W32Time service is suitable. Do not use tools that make periodic jumps.
Mod additions The EME CW mod has the same system requirements, with these notes:
  • Soundcard CW generation uses an extra 48 kHz / 16-bit output stream; any normal sound device is fine.
  • External paddle PTT detection uses a 100 ms polling interval on the CAT port in CW mode — verify the rig can be polled that often without lockups.
  • For 1 Hz Doppler resolution on 10 GHz the rig must accept 1 Hz CAT frequency commands.

4. Installation

4.1 Windows (EME CW Mod build)

  1. Download wsjtx-eme-mods-win64.zip from the GitHub Releases page.
  2. Extract to any location (e.g. C:\wsjtx-eme). The install is self-contained — all required DLLs (Qt 5.15, Hamlib 4.7.2, Boost 1.74, FFTW 3.3.5, MinGW runtime) are bundled in bin\.
  3. Run bin\wsjtx.exe.
Side-by-side with stock WSJT-X This build reads and writes the same configuration directory as stock WSJT-X (%LOCALAPPDATA%\WSJT-X). To keep both installations isolated, launch the mod with --rig-name=EME-CW — WSJT-X will store its settings and logs under %LOCALAPPDATA%\WSJT-X - EME-CW. See Platform dependencies for the full list of path overrides.

4.2 Upstream Windows installer

If you want vanilla WSJT-X, install from wsjt.sourceforge.io. Install into its own directory (e.g. C:\WSJTX), not under C:\Program Files. Log files live in %LocalAppData%\WSJT-X\.

Stock WSJT-X requires OpenSSL for the LoTW database fetch. If you see an SSL/TLS support not installed error, install the Light Win64 OpenSSL package from slproweb.com and the Microsoft VC++ 2013 x64 redistributable. The mod build bundles OpenSSL and does not require this step.

4.3 Linux

Upstream provides .AppImage, .deb, and .rpm packages. On Debian/Ubuntu:

sudo dpkg -i wsjtx_3.0.1_amd64.deb
sudo apt install libgfortran5 libqt5widgets5 libqt5network5 libqt5printsupport5 \
                 libqt5multimedia5-plugins libqt5serialport5 libqt5sql5-sqlite \
                 libfftw3-single3 libgomp1 libboost-all-dev libusb-1.0-0 libportaudio2

The mod has no Linux release ZIP; build from source (see release history for toolchain details).

4.4 macOS

Upstream provides .dmg packages for Apple Silicon and Intel. Use Audio MIDI Setup to force 48 kHz / 16-bit stereo. For USB-CODEC rigs that glitch after a few transmissions at 48 kHz, try 44.1 kHz. The mod has no macOS release ZIP; build from source.

4.5 Audio configuration (all platforms)

WSJT-X expects the sound card to sample at 48000 Hz. On Windows, open the Sound control panel → Recording and Playback → Properties → Advanced, and select 16 bit, 48000 Hz (DVD Quality). Disable all audio "enhancement" features.

4.6 Uninstall

Mod build: delete the extracted folder and (optionally) the %LOCALAPPDATA%\WSJT-X - EME-CW settings directory. Upstream build: use Windows Apps & features on Windows, sudo dpkg -P wsjtx on Debian, sudo rpm -e wsjtx on RedHat, or drag WSJT-X.app to Trash on macOS.

5. Menus

Menus at the top of the main window provide configuration, viewing, filtering, mode, decode, saving, and tools commands. Keyboard shortcuts appear at the right edge of each menu item.

5.1 File menu

  • Open / Open next in directory — replay a saved .wav file.
  • Open log directory — opens the folder containing wsjtx.log, wsjtx_log*.adi, ALL.TXT, and the Ignore List.
  • Erase wsjtx.log — resets the Wait-and-Pounce "worked before" index. Does not touch the ADIF log.
  • Erase Ignore List — empty the per-call mute list.
  • Export Cabrillo log... — with the mod, a Log source combo at the top of the export dialog lets you export from the internal contest log or from any wsjtx_log*.adi file in the log directory. MOD
  • Settings (F2) — opens the Settings dialog (chapter 6). On macOS this is Preferences under the WSJT-X menu (Cmd+,).
  • Exit — quit, saving all persisted settings.

5.2 Configurations menu

Multiple named configurations (default, FT8, Echo, EME-CW, …) can be cloned, renamed, and switched. Each configuration stores its own copy of every setting. Select a configuration from the command line with:

wsjtx --config EME-CW
wsjtx -c Echo

5.3 View menu

  • Astronomical data — opens the Doppler / Moon-tracking window (chapter 22).
  • Active stations — recent-decodes list; optionally fed by QMAP in 90 kHz wideband EME mode.
  • SWL mode — strips buttons and controls, leaving the decodes list and status bar (useful when running multiple instances).
  • Message creator / QSY monitor / Enable message popups — the HF/VHF/EME canned-message system.
  • Band buttons and VHF / UHF buttons — optional per-band QSY buttons. In FT8 mode, right-clicking an HF band button jumps to the DXpedition frequency.
  • Dark style — dark theme for all windows.

5.4 Filters menu

Toggles for hiding or ignoring stations by continent, worked-before status, Ignore List, Blacklist/Whitelist, etc. The BP checkbox on the main window bypasses all filters temporarily. Categories are defined on Settings > Filters (section 6.10).

5.5 Mode menu

Selects the current operating mode as an exclusive choice. Entries: FT4, FT8, FST4, FST4W, JT4, JT9, JT65, MSK144, Q65, WSPR, Echo — plus CW below the digital-mode separator. MOD

CW in the Mode menu Picking CW hides all digital-mode controls, shows the dedicated CW panel on the right, and sends Transceiver::CW to the radio via Hamlib. Picking any digital mode exits CW: digital controls return, and WSJT-X sends Transceiver::USB (or the configured Q65/Echo rig mode) to the radio. Mode-menu picks use the QActionGroup::triggered signal so internal mode changes do not re-fire rig commands. See section 12.2 for the full CW panel.

5.6 Decode menu

Selects decode depth (Fast / Normal / Deep) and in FT8 mode the number of parallel decoder threads. Also hosts Full-duplex mode and the mouse-click-on-waterfall guard for Q65 VHF features.

5.7 Save menu

Controls .wav file saving (per Rx sequence, or only decoded sequences), ALL.TXT rotation (monthly / yearly / off), and Diagnostic mode (extra logging for troubleshooting). Saved audio files can be scheduled for auto-deletion after 30 days.

5.8 Tools menu

Hosts Execute frequency calibration cycle, Solve for calibration parameters, Measure reference spectrum, Measure phase response, and Equalization tools. See chapter 16.

5.9 Help menu

Local copy of this user guide, keyboard-shortcut table, mouse-command table, release notes, and About WSJT-X. The mod's About dialog shows the line "Revised and modified by IT9CJC Marcello Criscione for EME and CW Microwaves use". MOD

6. Settings

Open Settings from the File menu or press F2 (Cmd+, on macOS, where it is called Preferences). The following tabs are available.

6.1 General

Enter your callsign, grid locator (6-character preferred), and IARU Region (1 = EU/AF/ME/N Asia, 2 = Americas, 3 = S Asia/Pacific).

Important options:

  • Enable VHF/UHF/Microwave features — disables wideband JT65 multi-decode and switches on VHF submodes, shorthand messages, EME delay, and the VHF-only band dropdown filter (below). Turn off for normal HF operation. MOD: with the mod, this flag alone drives the band dropdown content (see section 12.6).
  • Decode after EME delay — account for lunar round-trip delay before decoding.
  • Allow Tx frequency changes while transmitting — required for smooth Doppler tracking on microwave bands. Rigs known to support this: IC-735, IC-756 Pro II, IC-910-H, IC-9700, FT-847, TS-590S/SG, TS-2000 (rev 9+), Flex 1500/5000, HPSDR, Anan-10/100, KX3. IC-905 is confirmed working. MOD-tested
  • Double-click on call sets Tx enable — auto-start TX when selecting a station.
  • MSK144 / Q65: Tx until 73 is received — repeat 73 up to 10 times for marginal paths.
  • Enable Wait features — gates Wait and Reply / Wait and Call / Wait and Pounce.
  • Alternate F1-F6 bindings — function keys send Tx1-Tx6 directly; strongly recommended for contest-style FT4 / FT8.
  • Single decode — narrow decode window to F Tol, important in weak-signal EME where a 2nd signal distracts the Fano decoder.
  • Show DXCC, grid, and worked-before status — drives Decode highlighting and audio alerts.
  • Monitor returns to last used frequency — re-tunes the rig when Monitor is re-enabled after a band change.
  • Alternate Erase button behavior — left-click clears left, right-click clears right.
  • Language MOD — combo with System default / English. Overrides OS locale for the UI. Restart required. The --language command-line option takes priority over the stored setting when System default is selected.

6.2 Radio

Rig: select your radio from the Hamlib dropdown, or None for no CAT control. For software proxies (DX Lab Commander, FLRig, Ham Radio Deluxe, Hamlib NET rigctl, OmniRig Rig 1/2) select the proxy name and enter its network address if not local.

CAT control: set Serial Port, Baud rate, Data bits, Stop bits, Handshake. For USB-CAT radios, pick the virtual COM port created by the USB driver (not USB, which is for special USB devices like some SDR kits). Click Test CAT — the button turns green on success.

PTT Method: CAT, DTR, RTS, or VOX. For DTR/RTS, pick the serial port (may be the same as CAT). Click Test PTT — the button turns red while keying.

Transmit Audio Source: Rear/Data or Front/Mic (rigs that expose this choice).

Mode group box: this is the CAT mode WSJT-X will push to the rig when starting a non-CW digital session.

6.3 Audio

Select Input and Output devices (Mono usually suffices). Both must sample at 48 kHz / 16-bit. If the output device is also the system default, mute all system sounds to prevent them going over the air.

Save directory: where .wav recordings land. AzEl directory: where azel.dat is written (updated 1 Hz when the Astronomical Data window is open, for external moon-tracking programs).

Remember power settings by band: when checked for Tune or TX, the PWR slider remembers its position per band.

6.4 Tx Macros

Type a message (up to 13 chars incl. spaces) in the entry field, click Add. Drag-and-drop to reorder. The $DXCALL or $DX token at the start is substituted with the current DX Call on transmit. Macros are accessed from the main window's Tx5 dropdown.

6.5 Reporting

  • Prompt me to log QSO — raises the Log dialog after sending 73.
  • Log automatically — skip the dialog (not valid in contest modes).
  • Op Call — secondary operator callsign for multi-op stations.
  • Enable PSK Reporter Spotting — upload decodes to PSK Reporter.
  • UDP Server: address, port, and Accept UDP requests for JTAlert / Grid Tracker / N1MM+ / Writelog.

6.6 Frequencies

The Working Frequencies table lists per-mode, per-band default frequencies. Right-click to Insert / Delete / Reset. Double-click an entry to edit it. Mark entries Preferred to make them the default for the band button.

Frequency calibration: enter Intercept A (Hz) and Slope B (ppm) from a calibration run (see chapter 16). The rig frequency is corrected as dial_error = A + B·f.

Station Information: per-band Antenna Description and offset. For stock WSJT-X the offset is a simple fixed rig → sky number. In the mod the station-info offset is superseded by the per-band Transverter profile (see section 6.11 and section 12.7), and the old separate Offset tab (v3.0.6) has been removed.

6.7 Colors

Configure decode-highlighting by priority: My Call, DX Call in message, DX Grid in message, Transmitted message, New DXCC / state / grid / call per band, LoTW user, Ignore List, custom callsigns/grids. Drag rows to reorder; right-click to set FG/BG. Only grid Fields sought: 2-char Field (for Fields-worked awards) vs 4-char Square. LoTW user validation: Fetch Now downloads lotw-user-activity.csv from ARRL and highlights stations known to upload to LoTW within the configured window. CALL3.TXT files for terrestrial and EME use can be downloaded here too.

6.8 Advanced

JT65 Deep Search parameters: Random erasure patterns (6-7 is a good default), Aggressive decoding level, Two-pass decoding. Miscellaneous: Degrade S/N of .wav file, Receiver bandwidth, Tx delay (bump above 0.2 s if the rig needs longer to settle after PTT), ×2 / ×4 Tone spacing for LF transmitters.

Special Operating Activity: NA VHF / EU VHF / ARRL Field Day / FT Roundup / WW Digi / ARRL International Digital Contest / FT8 DXpedition Fox / SuperFox / Hound.

6.9 Audible Alerts

Plays sounds on decodes matching selected categories. Requires at least two output devices (one for Tx audio, another for alerts). Alerts always route to the system Default device. The BP checkbox on the main window bypasses Ignore List muting of alerts. Right-click the Band Hopping button plays a test sound so you can confirm the alert output device is not the radio.

6.10 Filters

Up to four Hide-territory categories, plus Blacklist / Whitelist / Always Pass lists (callsigns, call fragments, keywords, grids). Toggles live on the main Filters menu. Filters apply to transmitting-station calls, and optionally only to Wait-and-Pounce. Status bar turns cyan Receiving, Filters on when any active filter is hiding decodes.

How to use:

  1. Enter the transverter's IF frequency (MHz, 3 decimals) in the row's IF column. Offset updates live.
  2. Tick Enabled on the one band you intend to operate. Enabling a row automatically un-ticks the previous one (mutually exclusive, enforced at the UI level and again on read-back).

CAT frequency pipeline: when a band is enabled,

offset   = band_center − IF

Both RX and TX use the same offset. Example — 3 cm (10368 MHz) with IF = 432 MHz → offset = 9936 MHz. Dial 10368.100 MHz → rig gets 432.100 MHz; the rig's reported 432.100 MHz is translated back to 10368.100 for display, Doppler math, and logging.

Status indicator: a persistent IF label appears in the status bar next to the rig-mode label:

  • IF=NONE — no transverter active, rig sees the WSJT-X dial directly.
  • IF=432.000 MHz — a band is active; label shows the configured IF.

8. Transceiver setup

First-time setup after installing WSJT-X and configuring the Radio tab:

  1. Receiver noise level. Click Monitor. Set rig gain and PC audio-mixer so the background noise bar at the lower left reads around 30 dB with no signals. Turn AGC off or reduce RF gain to minimize AGC action.
  2. Bandwidth. Set the rig to USB (or USB-Data) and open the IF filter to the maximum, up to 5 kHz. If only a 2.7 kHz SSB filter is available, use that; the active FT8 band is still visible.
  3. TX audio level. Click Tune. The rig should transmit a steady tone. Watching the rig's power meter, pull the Pwr slider (at the right edge of the main window) down until RF output drops just slightly from maximum. Stop tune with Tune again or Halt Tx.
  4. Monitor the tone via the rig's monitor function. It should be clean, with no clicks, dropouts, or glitches — even while the PC does other work (browsing, email). Clicks almost always mean audio clipping, buffer underruns, or interference from another process (anti-virus scans, Windows audio enhancements).
For EME CW specifically When CW is selected from the Mode menu, the normal Tune button is replaced by the CW panel's own Tune (700 Hz CW tone) and a separate Stop button. The soundcard-CW path drops the rig into Data/PktUSB for TX, so you cannot use the TX tone to set the CW-mode drive level. Set your CW drive on the rig itself (CW power control, side-tone, keyer speed) — WSJT-X only handles timing and Doppler, not CW audio shaping.

9. Basic operating tutorial

The fastest way to get comfortable with WSJT-X is to replay a sample .wav file. Help > Download samples… fetches a set of audio clips; for the tutorial you need the FT8 files at minimum.

9.1 Wide Graph settings

The Wide Graph window shows the frequency spectrum of received audio. Recommended starting point:

  • Start = 100 Hz
  • Bins/Pixel = 5
  • N Avg = 2
  • Palette = Fldigi (or your preferred)
  • Flatten checked (compensates for passband slope)
  • Spec = 50 % (vertical split between waterfall and line plot)
  • Gain / Zero sliders at midscale

Resize the Wide Graph so the top frequency is about 3300 Hz.

9.2 FT8 replay

  1. Stop, then Mode > FT8, Decode > Deep. Double-click Erase.
  2. File > Open → navigate to save/samples/FT8/210703_133430.wav.
  3. Observe the left pane (Band Activity) fill with decodes and the right pane (Rx Frequency) with messages at the current Rx frequency or addressed to your My Call.

10. Making QSOs

10.1 Standard exchange

A minimally valid WSJT-X QSO exchanges callsigns, a signal report, and acknowledgments:

CQ K1ABC FN42                       # K1ABC calls CQ
                K1ABC G0XYZ IO91    # G0XYZ answers
G0XYZ K1ABC -19                     # K1ABC sends report
                K1ABC G0XYZ R-22    # G0XYZ sends R + report
G0XYZ K1ABC RRR                     # K1ABC sends RRR (or RR73)
                K1ABC G0XYZ 73      # G0XYZ sends 73

Signal reports are S/N in dB referenced to a 2500 Hz bandwidth. JT65 reports are constrained to −30…−1; JT9 and the 77-bit modes support −50…+49. Double-clicking Tx1 toggles starting with Tx2 instead; double-clicking Tx4 toggles RRR vs RR73.

10.2 Free-text messages

Up to 13 characters, including spaces. Avoid / (parsed as compound-call separator).

10.3 Auto-Sequencing

Check Auto Seq to let WSJT-X pick the next Tx message based on what it just decoded. CQ-reply mode selectable: First, Max dB, Min dB, Max Dist. The Call 1st checkbox forces reply to the first responder; the CQ dropdown handles longer-term selection strategy. Auto Seq auto-disables Enable Tx at the end of each QSO — WSJT-X will not run back-to-back fully automated QSOs.

10.4 Wait features

  • Wait and Reply — continue a QSO when the called station resumes. DX Call field + Enable Tx turn yellow.
  • Wait and Call — click the DX Call label (turns red) to try up to three times automatically when the station reappears with CQ / RR73 / RRR / 73.
  • Wait and Pounce — clear DX Call, pick a CQ type, right-click Enable Tx (turns orange). WSJT-X will auto-reply to CQs matching the selection and the active Filters.

10.5 Contest messages

FT4 / FT8 / MSK144 support dedicated contest message formats for NA VHF, EU VHF, ARRL Field Day, FT Roundup, WW Digi, and ARRL International Digital Contest. Activate the appropriate activity on Settings > Advanced. Contest mode disables Filters by default so you do not miss stations.

10.6 Nonstandard callsigns

77-bit modes (FST4, FT4, FT8, MSK144, Q65) support compound calls like PJ4/K1ABC or YW18FIFA via hash-code shortcuts in angle brackets. 72-bit modes (JT4, JT9, JT65) handle them as Type 1 or Type 2 compound calls depending on whether the prefix/suffix is in the short list. See the upstream User Guide for full details and examples.

10.7 Pre-QSO checklist

  • Callsign and grid locator set.
  • PTT and CAT control tested (Test CAT / Test PTT green and functional).
  • PC clock within ±1 s of UTC.
  • Audio devices at 48 kHz / 16-bit.
  • Rig on USB, filters wide (up to 5 kHz).
  • For EME: Enable VHF features on, Decode after EME delay on, Split operation set.
  • For CW EME MOD: CAT-keyer vs soundcard decided (CW panel checkbox); Sked frequency set; Doppler mode picked; Astro dialog open.

Soundcard path, step-by-step:

  1. Switch rig to Data/PktUSB, wait 50 ms.
  2. Assert PTT, wait 200 ms (rig settle).
  3. Stream CW tone via SoundOutput on audio_output_device. 48 kHz, 16-bit mono PCM, PARIS timing (dit = 1200/WPM ms), 5 ms raised-cosine ramps, full A-Z/0-9/basic-punct Morse table.

Why this switch exists Marcello's rig is an Icom IC-905. The CAT keyer path via Hamlib SEND_MORSE is unreliable on it under current Hamlib builds — messages are truncated, speed is sometimes wrong, and PTT release can hang. The soundcard path works on any rig that can be put into Data/PktUSB and keyed via PTT, so it's the reliable fallback. For rigs with solid SEND_MORSE support (Icom IC-7300, Yaesu FT-991A, Kenwood TS-590S/SG, etc.) leave the checkbox checked.

Auto-detected default at startup: CAT-keyer checked if the Hamlib backend reports SEND_MORSE capability, soundcard otherwise. The explicit checkbox always wins over the auto-detection.

12.9 External paddle PTT & dial freeze MOD (v3.1.0-devel)

You can operate CW with an external keyer / paddle plugged straight into the rig while WSJT-X handles Doppler correction. When CW mode is active:

  • PollingTransceiver::set_poll_interval(100) ms — CAT is polled 10×/second.
  • PTT edge in handle_transceiver_update() fires cwDopplerUpdate(bool tx), which applies the correct RX / TX direction of the Doppler correction.
  • During TX, a 1 Hz refresh timer updates the correction continuously.
  • CW_DOPPLER_MIN_DELTA_HZ = 5 filter prevents dial flicker from sub-Hz recalculation noise.
  • TX Hold ms (CW panel setting) debounces semi-break-in: a brief RX during a long QSO does not yank the rig back to the RX leg.

Dial-freeze during CW TX: the main window's dial stops reading m_rigState.frequency() during any CW TX (soundcard, paddle, Tune). This eliminates the RX/TX flicker you otherwise see as the rig toggles between its RX and TX VFOs. The dial resumes live reading as soon as TX drops.

  2. Check Keep CQ, set the timeout (default 10 min).
  3. Start a QSO normally. On the final 73:
    • Auto stays on.
    • Tx6 (CQ) is selected automatically.
    • Watchdog armed for N minutes.

12.13 JT4

Designed for microwave EME (2.3 GHz and above). Submodes JT4A…JT4G offer tone spacings 4.4…315 Hz for increasing Doppler spread. Submode JT4F is typical for 5.7 and 10 GHz EME. Check Sh to enable short-form single-tone messages (OOO / RO / RRR / 73). Tx6 toggles between 1000 Hz and 1250 Hz calibration tones. Select Decode > Deep, optionally with Enable averaging and Enable deep search.

12.14 JT65

Submodes JT65A (177 Hz), JT65B (353 Hz), JT65C (703 Hz) for increasing Doppler spread. Typical allocation: 50 MHz → A, 144/432 MHz → B, 1296 MHz → C. Enable VHF features; check Single decode; skip Two pass. Shorthand messages (OOO / RO / RRR / 73 as two-tone signals) are decoded automatically and can be auto-generated with the Sh checkbox. Enable AP, Enable Deep search, and Auto Clear Avg further boost sensitivity at the cost of a slightly higher false-decode rate.

12.15 Q65

Preferred mode for VHF+ EME and ionospheric / tropo scatter. Submodes A–E with tone spacings 1–16× the keying rate, and T/R periods 15–300 s. Recommended combinations: Q65-60A for 50/144 MHz, Q65-60B for 432, Q65-60C for 1296 / 2320, Q65-60D for 3400 / 5760, Q65-60D or E for 10368, Q65-60E for 24 GHz+. AP decoding is always enabled and progressively uses your call, DX call, and DX grid as they become known. Mouse-click-on-waterfall can be disabled from Decode menu so you don't accidentally change Rx/Tx offsets — hold Alt to re-enable per-click.

12.16 MSK144

Meteor scatter. Fixed 1500 Hz center, 2400 Hz bandwidth, 15 s or 30 s T/R. Check Fast decoder. The Offset CQ feature ("Tx CQ nnn") lets you CQ on one frequency and conduct the QSO on another — requires CAT and Split. Short-form messages (Sh checkbox) at 20 ms let short pings carry the whole message. For 50 / 70 MHz the pings are usually long enough to use full 72 ms messages.

12.17 Echo mode

Detect and measure your own lunar echoes. A 2.048 s 1500 Hz tone is transmitted every 6 s cycle, and the returned spectrum is averaged in the Echo Graph. Optional Fixed Tone, MFSK, or CW echo transmission types. The Avg spinner averages the specified number of cycles. Line output per cycle: UTC, Hour, Level (dB), Doppler, Width, N, Q, DF, SNR, dBerr. With Doppler tracking set to Own Echo or Constant Moon, WSJT-X handles T/R, frequency corrections, and the 2.5 s round-trip delay automatically.

12.18 Tips for EME

From the upstream guide, with mod-specific additions:

  • Preferred digital modes per band: Q65-60A on 50 / 144 MHz, Q65-60B on 432, Q65-60C on 1296 / 2320, Q65-60D on 3400 / 5760, Q65-60D or E on 10368, Q65-60E on 24 GHz+.
  • JT4, JT65, and Q65 offer message averaging — sum of successive transmissions conveying the same message — which decodes at S/N a few dB below single-tx threshold.
  • For CW EME on microwaves: put the rig in CW mode (via Mode menu → CW), check Doppler tracking in Astro, pick the Doppler method appropriate for the sked. Use the CW panel's Tune for amp warm-up.
  • Large additional dial-frequency offsets for cross-band EME: set Sked to the RX freq, then use Tx Shift in the Astro dialog (±200 MHz in the mod, see section 12.10). Example: RX 1296 MHz, Tx Shift = +2 MHz → TX on 1298 MHz.
  • For CW EME QSOs without the CW Mode menu entry (legacy style): put the rig in CW mode manually, set Settings > Radio > Mode to None, use the standard WSJT-X Tune button as a push-to-transmit (no audio tones generated in rig CW mode, but WSJT-X still updates the dial for Doppler). Click Tune again to return to RX.

13. WSPR mode

WSPR (Weak Signal Propagation Reporter, "whisper") is designed for probing propagation paths using low-power beacon transmissions. WSPR messages carry callsign, grid, and power in dBm, and decode down to about −31 dB SNR in a 2500 Hz bandwidth. FST4W is a modern alternative for LF/MF with sequence lengths up to 1800 s and sensitivity down to −45 dB.

Setup:

  1. Mode > WSPR. The main window reconfigures.
  2. Set Wide Graph: Bins/Pixel 1, N Avg 5, Start 1400 Hz, width around 200 Hz.
  3. Select an active WSPR frequency (10.1387 MHz, 14.0956 MHz, etc.). Check your local regulations before TX on 60 m.
  4. Monitor to start 2-minute Rx periods.
  5. Set Tx Pct (percent of periods devoted to TX, randomly placed to reduce clashes) and your TX power (dBm from the dropdown).
  6. Enable Tx to go live.

13.1 Band hopping

Check Band Hopping and click Schedule to open the WSPR Band Hopping window. For a CAT-controlled rig, WSJT-X moves between bands on a 20-minute repeating schedule tied to UTC minutes. Checking Tune for a band causes an unmodulated carrier to be sent on band change (useful for automatic ATU tune-up). A user-supplied script user_hardware <band> (or executable on the PATH) is run after each band switch, for antenna / preamp / filter switching.

15. Decoder notes

15.1 A priori (AP) decoding

FST4, FT4, FT8, JT65, and Q65 decoders can use known-in-advance message bits ("AP information") to boost sensitivity by up to 4 dB, at the cost of a slightly higher false-decode rate. AP is optional in FT8/JT65; always on in Q65, FT4/FST4 Normal and Deep.

Example: you decided to answer a CQ. You know your own call, your partner's call, and likely message type — that's 57 bits already. The decoder needs to resolve only the remaining 15 bits (report / R-report / RRR / 73). Successful AP decodes are tagged aP on the decoded line, with P indicating the AP type (see upstream guide for the full AP-type tables).

Decoder output format:

UTC  SNR  DT  Freq  Mode  Message  [sync]  [aP]  [?]
  • Mode character: ~ FT8, + FT4, ` FST4, # JT65, : Q65, & MSK144, @ JT9, $ JT4.
  • ? — decoded with lower confidence (not forwarded to PSK Reporter).
  • aP, qP — AP / Q65 AP decode with type P.
  • fN — Franke-Taylor / Fano, N averaging intervals.
  • dCN — Deep Search, confidence C, N intervals.

15.2 Full-duplex mode

Decode > Full-duplex lets WSJT-X transmit and receive simultaneously. Audio input comes from a second local Rx or a WebSDR. Your own transmitted messages are highlighted in the Band Activity window with the "Transmitted message" color from Settings > Colors.

16. Measurement tools

16.1 Frequency calibration

Dedicated FreqCal mode for CAT-controlled rigs. Define a per-location list of carrier references (AM broadcast stations, WWV at 2.5 / 5 / 10 / 15 / 20 MHz, CHU at 3.330 / 7.850 / 14.670 MHz) in Settings > Frequencies. Check Tools > Execute frequency calibration cycle to step through them, 30 s per freq. Check the Measure option to accumulate data into fmt.all.

After one or more cycles, Tools > Solve for calibration parameters fits a line and offers an Apply button that writes Intercept A and Slope B into Settings > Frequencies > Frequency Calibration. See FMT_User.pdf for a detailed walk-through.

16.2 Reference spectrum

Tune to a quiet band, check Flatten on the Wide Graph, run Tools > Measure reference spectrum, wait about a minute, click Stop. The file refspec.dat appears in the log directory. Check Ref Spec on the Wide Graph to apply it.

16.3 Phase equalization

MSK144 feature for compensating group-delay variation across the Rx passband. Record .wav files with decodable signals from a reference station (one with linear transmit phase, no multipath). Enter the reference call in DX Call, run Tools > Measure phase response, open each file. The result is saved as a CALL_YYMMDD_hhmmss.pcoeff file. Open Tools > Equalization tools > Phase… to view the measured data and fitted curve; click Apply to make it active. The Group Delay curve appears (ms across the passband). To revert, Restore Defaults + Apply.

Judge improvement by the three numbers at the end of each MSK144 decode line: N frames averaged, H hard errors corrected, E eye opening. Smaller N is strictly better (fewer frames needed for a decode); E is on a −2…+2 scale with larger-positive = better.

19. Frequently asked questions

My displayed spectrum is flatter when I do not check Flatten. What's wrong?

WSJT-X does not expect a steep filter edge within the displayed passband. Widen the IF filter, or reduce the displayed passband (decrease Bins/Pixel, increase Start, reduce Wide Graph width, or re-center the filter passband).

How do I run multiple WSJT-X instances?

Start from a command prompt with unique --rig-name values:

wsjtx --rig-name=TS590
wsjtx --rig-name=FT847

Network error "SSL/TLS support not installed".

Stock build: install OpenSSL Light for Win64 and (if still failing) the VC++ 2013 redistributable. Mod build: OpenSSL is bundled, so you should not see this.

Icom rig CAT control is flaky when I twirl the VFO.

Disable CI-V Transceive in the rig's menu. Unsolicited CAT traffic breaks polling.

Can I share rig control between WSJT-X and another program?

Only via a rig-control server: Hamlib rigctld, OmniRig, or DX Lab Commander. Serial-port splitters (e.g. VSPE) are unreliable — unmanaged CAT collisions bite.

Rig frequency shifts slightly on RX → TX in FT8/FT4. Problem?

No. When Split is on and your Tx audio frequency falls outside 1500–2000 Hz, WSJT-X moves the rig to keep the actual tone inside 1500–2000 Hz — this avoids in-band audio harmonics and SSB-filter skirt issues. Normal.

Ubuntu: menu bar missing from the main window.

sudo apt remove appmenu-qt5

Or run with an empty QT_QPA_PLATFORMTHEME:

QT_QPA_PLATFORMTHEME= wsjtx

KDE: Configurations menu misbehaves.

Edit ~/.config/kdeglobals:

[Development]

MOD FAQ: SEND_MORSE is unreliable on my Icom IC-905.

Expected. Uncheck CAT keyer in the CW panel to use the soundcard path (see section 12.8). Make sure Settings > Radio > Q65/Echo Rig Mode is set to a mode the rig advertises (Data/PktUSB on the IC-905) or you will hit the silent-fallback-to-USB logic.

MOD FAQ: Band-button QSY crashes WSJT-X.

Fixed in v3.1.3-devel. Astro::applySkedFreqMHz no longer emits skedFreq — the emit caused infinite ping-pong between band_changed and applySkedFreqMHz. The signal still fires on explicit Set-kHz clicks (user input), which is the only legitimate case.

MOD FAQ: Switching Q65 → CW requires two clicks.

Fixed in v3.1.3-devel. updateCWModeUI no longer calls ui->actionCW->setChecked(cw_mode) — the re-check was undoing actionQ65->setChecked via QActionGroup exclusivity. See section 12.2.

MOD FAQ: Band dropdown shows only VHF entries after switching to CW.

Fixed in v3.1.3-devel. The dropdown filter is driven solely by Settings > General → Enable VHF features, not by decoder mode. See section 12.6.

MOD FAQ: Transverter offset breaks other bands.

Fixed in v3.1.0-devel. The offset is only applied when the sky frequency falls inside the enabled band's hard-coded range. Outside the range, offset = 0 and the status bar shows the grey IF=28.000 (idle) hint. See section 12.7.

20. Protocol specifications

All WSJT-X QSO modes use compressed fixed-length message payloads. JT4, JT9, and JT65 use 72-bit payloads (two 28-bit callsign fields + 15-bit grid/report/ack + 1-bit free-text flag). FST4, FT4, FT8, Q65, and MSK144 use 77-bit payloads (5 extra bits for nonstandard calls, contest exchanges, SuperFox, etc.).

TX Shift has no effect.

  • Baud rate mismatch.
  • Another program is holding the COM port.
  • Try a different Hamlib entry for the same rig (some have firmware variants).

A. EME CW Mod — operator-visible design rules

These behaviors have been established across v3.0.2 through v3.1.4-devel and are load-bearing — reintroducing an older assumption will silently break something that was fixed at real debugging cost. Listed here so operators understand "why does WSJT do X" when the answer is "because doing Y would break Z."

  1. Band dropdown filter = f(Enable VHF features) ONLY. Content depends solely on Settings > General → Enable VHF features, not on current decoder mode. Applied via FrequencyList::set_vhf_only_filter(bool) at startup, in switch_mode, and in handle_leavingSettings. Section 12.6.
  2. Band-dropdown pick → sked, in every Doppler method. Operator picks always win. Sticky-sked override is skipped when m_bandEdited is true, protecting user intent against code-initiated QSYs. Section 12.6.
  3. Rig VFO → sked ONLY in Doppler = None (method 0). Call DX (method 5) is sked-master — WSJT drives the rig; operator VFO moves are reverted. rig_master = (method == 0) in both astroUpdate and handle_transceiver_update. Section 12.4.
  4. Astro::applySkedFreqMHz does NOT emit skedFreq. The emit caused infinite band_changed ↔ applySkedFreqMHz ping-pong on band-button QSY (stack blown). The signal fires only on explicit Set kHz clicks in the Astro dialog.
  5. updateCWModeUI does NOT touch ui->actionCW->setChecked. It used to reassert on every call, which during on_actionQ65_triggered → setup_status_bar → updateCWModeUI undid actionQ65's own setChecked via QActionGroup exclusivity → two-click Q65 bug. Mode-menu check state is managed by Qt's QActionGroup. Startup CW restoration lives in the existing QTimer::singleShot(0, …) safety-net in the MainWindow constructor.
  6. Astro Ctl-Lock Sked Freq gates main-window-driven sked updates. When locked, band-dropdown picks and VFO adoption (Doppler = None) do not change m_skedFreq or Astro sked labels. The main dial still follows the VFO so it stays accurate — only the sked is frozen. Hold Ctrl to force a one-shot sked push.
  7. CW layout centering via gridLayout_5 column-6 stretch. gridLayout_5 default column stretch is 0,0,0,0,1,1,5,0. Column 6 holds controls_stack_widget (stretch 5 → 5/7 of extra width). In CW the widget is hidden; leaving stretch at 5 jams dial + bandComboBox left and clips "80m" to just "m". updateCWModeUI zeros column-6 stretch in CW, restores 5 in digital. bandComboBox->setMinimumWidth(120) in CW, 0 in digital.
