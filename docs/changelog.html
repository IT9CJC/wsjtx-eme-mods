v3.0.3-devel Latest

2026-09-06

Bug fixes and new features for EME CW operation. Version bumped to 3.0.3.

Bug Fixes

  • TX Shift frequency display — When "Enable Shift" is checked, the Sked TX frequency label now shows the actual shifted TX frequency (RX + Shift) in blue text instead of the unhelpful "N/A Tx Shift!" message. FIX

New Features

  • Fine frequency wheel control — The dial frequency mouse wheel now supports modifier keys for sub-kHz tuning: no modifier = 1 kHz, Shift = 100 Hz, Ctrl = 10 Hz, Ctrl+Shift = 1 Hz. NEW
  • CW mode status indicator — A blue "CW" label appears in the main window status bar when CW data mode is active in Settings > Radio > Mode. Hidden when any other mode is selected. NEW
  • Version bump to 3.0.3-devel — Project version updated in CMakeLists.txt; reflected in the About dialog and all version strings. NEW

v3.0.2-eme-cw

2026-09-06

Initial release of the EME CW modifications, based on upstream WSJT-X 3.0.2-devel.

New Features

  • CW rig mode via CAT — New "CW" radio button in Settings > Radio > Mode. Commands the transceiver into CW mode through Hamlib (RIG_MODE_CW) while Doppler tracking remains fully active on both RX and TX. NEW
  • TX Shift extended to ±200 MHz — The TX Shift spinbox in the Astronomical Data window now accepts values from −200 to +200 MHz (was ±30 MHz). NEW
